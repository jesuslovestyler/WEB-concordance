# WEB Concordance — every word in the Bible, findable

A concordance of the **World English Bible**: look up any word and see everywhere it appears in Scripture, with the verses themselves.

**Live:** https://jesuslovestyler.github.io/WEB-concordance/
**Home:** https://jesuslovestyler.com/

Built from the World English Bible text — a public-domain modern English translation by Michael Paul Johnson and many volunteers (eBible.org) — so the concordance is public domain too. One self-contained page: no account, no ads, nothing to buy. Open it, search a word, and follow it through the whole Bible.

Companion to the [World English Bible app](https://github.com/jesuslovestyler/World-English-Bible) and the [interlinear Study Bible](https://github.com/jesuslovestyler/Study-Bible).
